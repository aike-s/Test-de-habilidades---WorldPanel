*** JSON ***
Implemente en un archivo en formato JSON sus datos personales
Nombre, edad, teléfono, ubicación y contemple implementar un vector de hobbies.
JSON

const usuario = {
    "nombre": "Salome",
    "edad": "26",
    "telefono": "3223148681",
    "ubicacion": "Bogota",
    "hobbies": ["cine", "caminatas", "aprendizaje", "lectura]
}

¿Cómo accederías al valor de edad en el siguiente JSON?
Respuesta: usuario.edad
Alternativa: usuario['edad']
